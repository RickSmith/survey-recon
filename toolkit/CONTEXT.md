# CONTEXT.md — the words we use at «FIRM NAME»

**This file is the project file the new hire reads before driving to site.**

The agent reads it before it does anything. Its whole job is to stop the agent
guessing what a word means. An agent that guesses will pick the common meaning,
and in this trade the common meaning is often the wrong one. "Monument" means
something specific. So does "recovery", "control", and "closure".

Start small. **Six words you are tired of explaining is a better first version
than fifty words copied out of a textbook.**

## How this file grows

Nobody sits down and writes a glossary. It accumulates.

**Add a word when any of these happens:**

- You explain the same term twice in one week
- The agent uses a word you would not have used
- Two people in a meeting turn out to mean different things by the same word
- You catch a document using a synonym for something already in here

**The agent adds words too.** `/grill-with-docs` writes into this file as terms
get settled during the interview — that is most of what it is for. Read what it
adds. It will get some of them wrong, and the wrong ones are useful, because a
word the agent misunderstood is a word your documents were unclear about.

**If a word is not in here and you need it, that is one of two things.** Either
the word is being invented on the spot, which is worth stopping for. Or there is
a real gap, and it belongs in this file.
