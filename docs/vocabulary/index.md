# Vocabulary

Software people built a way of working that fits an agent exactly: write the
job down, work on a copy, check the print, sign it. They also gave every part
of it a name that means nothing to a surveyor. This page is the translation.

Every software word on this site is introduced by its survey meaning first,
and then used sparingly. If you meet one that is not here, it should be. Say
so.

## The words you will meet

| What the software calls it | What it is |
|---|---|
| **Issue** | A work order. One job, written down, with a number, before anybody starts it |
| **Branch** | A working copy nobody else is affected by. The agent works here, never on the real thing |
| **Commit** | A field book entry. One change, with a note saying why, and a date |
| **Pull request** | The check print you redline. The agent hands its copy back and a person reads it |
| **Merge** | You sign and seal. The work goes from the copy into the real thing, and your name is on it |
| **Spec** | The scope of work |
| **Code review** | Checking the work before it goes out the door |
| **Rewriting history** | Going back and altering field book entries already made. This site has a rule against it, and [broke it once](../managing-your-agent/the-force-push.md), on purpose |
| **Force push** | Tearing a page out of the field book and writing a new one in its place |
| **Markdown** | Plain text with a few marks in it. Anybody can read it, and it opens in nine years without software |
| **Context window** | What is spread on the desk right now. Anything not on the desk might as well not exist |
| **Token** | A crew-hour for the machine. The unit the tool counts and bills you in. Never the unit you bill a client in |
| **Skill** | A written procedure the agent reads before it starts. The one-page procedure taped inside the truck |
| **Slash command** | How you call for a skill by name. You type `/grill-with-docs` and the agent opens that procedure |
| **Repo** | The job folder. Everything about one job, with its whole history, in one place |
| **Cache** | Saved copies of every answer a public service gave, with the date and the exact question beside each. A photocopy of the deed you worked from, filed with the job |

## Two words the surveying side owns

The rest of the site uses the surveying words the way you do, and the software
side has to learn them. Two come up on nearly every page and are worth saying
once, because the whole argument rests on them.

**Responsible charge.** The sealing surveyor is accountable for work done under
their supervision, whoever or whatever did it. In the Texas rules it is the
same standard as direct supervision, not a looser one. 22 Tex. Admin. Code
§ 131.2(38).

**Direct supervision.** Control over, and detailed professional knowledge of,
the work, and personally reviewing and approving proposed decisions *before
they are acted on*. 22 Tex. Admin. Code § 131.2(11). The word *before* is the
part that shapes how an agent has to be worked, and it is why every job here
goes through a check print.
