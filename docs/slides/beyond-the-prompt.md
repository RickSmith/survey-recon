# An agent is a new employee

- **Capable, fast, and tireless.** It reads faster than you do and never gets bored.
- **Occasionally confidently wrong** — in the same way a bright new hire is confidently wrong.
- **Managing one takes what managing anybody takes:** a clear scope of work, small assignments, visible progress, and somebody checking the work before it goes out the door.

**You seal it. You own it.** That part does not move.
