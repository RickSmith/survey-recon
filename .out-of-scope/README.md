# Things we decided not to build

This folder holds the requests that were turned down, and why.

A closed work order says *no*. It does not say *no, and here is the thinking*,
and six weeks later nobody remembers which it was. So the reasoning lives here
instead, in a file per idea rather than a file per work order.

**It is a rejection file, not a to-do list.** Nothing in here is waiting to be
built. If something in here should be built after all, delete its file and open
a fresh work order. The old work order stays closed — it is history, and this
repo does not rewrite history.

**Nothing that was already built belongs here.** A request that turns out to be
done is closed by pointing at where it lives. Filing it as a rejection would
teach the next reader that a feature we shipped is one we refused.

`/triage` reads this folder before it looks at a new work order, so an idea that
comes round a second time is met with the first answer rather than a fresh
argument. That is the whole point of writing it down.

## The survey version of this

It is the note in the file that says why the crew did not set a monument at a
corner. The corner is still there. The decision not to set it was made by
somebody, for a reason, on a date — and the next crew out should be able to read
that instead of guessing.
